# GitHub Copilot facts (snapshot 2026-09)

Billing changed in 2026 and is still evolving. Quote these with the date, and check the source when the answer matters.

## Billing

- From 2026-06-01, Copilot moved from premium requests to usage-based billing with GitHub AI Credits. Usage is metered by input, output and cached tokens at each model's listed API rate. 1 AI Credit = $0.01.
- Plan prices stayed the same and include the same amount in credits: Pro $10/month ($10 of credits), Pro+ $39/month ($39), Business $19/user/month ($19), Enterprise $39/user/month ($39). Business and Enterprise got extra promotional credits for June to August 2026, and organizations pool included usage.
- Code completions and next edit suggestions remain included on all paid plans and do not consume AI Credits.
- Admins can set budgets at enterprise, cost center and user level, and choose to allow or block overage.
- Pro and Pro+ subscribers on an existing annual plan could stay on legacy request-based billing: requests multiplied by a per-model multiplier, a 10% multiplier discount for Auto model selection, code review at a multiplier of 13 from 2026-06-01, and extra requests at $0.04 each. Unused requests do not roll over.
